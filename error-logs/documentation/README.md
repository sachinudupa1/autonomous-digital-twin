Owner: Teammate 4 - Shravya.

error logging and Main-Agent decision logging system.

1. Individual agent error events.
2. Main-Agent decision events.
3. Error categories.
4. Decision history.
5. Previous mistake analysis.

Firestore persistence.

to GitHub.
