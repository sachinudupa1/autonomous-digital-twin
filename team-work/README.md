# Team Workspaces

This directory contains the documentation and evidence workspaces of all five teammates.

- teammate-1: Project Owner, websites, Digital Twin, 3D models and integration.
- teammate-2: Reinforcement Learning Agent and five conventional baselines.
- teammate-3: FastAPI backend, Machine Learning Agent and Firestore Admin SDK integration.
- teammate-4: Main Agent, proposal evaluation, decision logging and reports.
- teammate-5: Synthetic machine-health data and Rule-Based Agent.

Actual application and source code belongs in the central directories at the repository root.

Each teammate workspace contains task folders, daily-reports and handover.
